# Extra Capstone Problems

27 open-ended capstone simulation studies for *Simulation Without a Black Box*.

## Contents

| File | Description |
|---|---|
| `extra_problems.tex` | Main LaTeX source — all 27 problems |
| `data/ep25_districts.csv` | District map for EP25 (fire station siting) |

## Building

From the repository root: `make course/problem_bank/extra_capstones/extra_problems.pdf`
(or `make problems`).
